# 🌍 API de Países - PostgreSQL & MongoDB

API RESTful para gestionar información de países utilizando bases de datos relacionales (PostgreSQL) y no relacionales (MongoDB).

## 📋 Requisitos Previos

- Node.js v16 o superior
- PostgreSQL
- MongoDB

## 🚀 Instalación

1. Clona el repositorio:
```bash
git clone https://github.com/ZundyTor/API-BDNoSQL.git
cd API-BDNoSQL
```

2. Instala las dependencias:
```bash
npm install
```

3. Configura las variables de entorno:
```bash
cp .env.example .env
# Edita el archivo .env con tus credenciales
```

4. Inicia el servidor:
```bash
npm run dev
```

## 🧪 Prueba la API

Abre tu navegador en: `http://localhost:3000`
